# 决策记录 · 预览文案与数据口径（2026-11-10）

> 只记录**为什么**。怎么实现看 `presentation/index.html`；仓库规则看 `AGENTS.md`。

## D1 预览做成单文件 + 内嵌字体

- **背景**：需求要求“单文件或少量文件，便于直接打开查看”，且项目强调断网可演示。
- **选择**：`presentation/index.html` 自带全部 CSS/JS/数据；字体单独放 `assets/fonts.css`，
  Geist / Geist Mono 以 base64 内嵌。
- **理由**：评审双击即可看；不依赖 npm、CDN、本地服务器。
- **影响**：文件较大（约 97 KB），改样式需直接编辑 HTML；字体只在 `latin` 子集内嵌，
  中文回退系统字体（PingFang / 微软雅黑）。

## D2 预览用内联 SVG，不引入 ECharts

- **背景**：原前端用 1 MB 的本地 ECharts；参考页的曲线是 CMS 图片。
- **选择**：预览里的折线、范围条、睡眠阶段、评分盘全部手写 SVG。
- **理由**：零依赖、可做路径描边动画、与 Mira 的细线风格一致；正式版是否保留 ECharts 未定。
- **影响**：预览的图表交互（hover/tooltip）没有做，只有入场动画；正式版需要补。

## D3 界面全中文

- **背景**：原预览大量英文 mono 标签（MARKERS TO WATCH、Optimal/Watch/Low 等），
  用户 2026-11-10 明确要求“所有英文改为中文”。
- **选择**：标签、单位、状态、表头、Toast、`aria-label` 全部中文；
  状态词统一为 `达标 / 关注 / 偏低`；单位统一 `次/分 / 毫秒 / 分钟 / 小时 / ℃`；
  术语 `心率变异性 / 快速眼动 / 长短期记忆网络 / 平均绝对误差`。
- **例外**：`维生素D3` 保留 D3（维生素通用写法）；若要求零拉丁字母，可改“胆钙化醇”。品牌名后按用户要求保留英文，见 D9。
- **影响**：`frontend/` 未按此改写，仍是原样；不要在未确认时套用。

## D4 对话与问候称呼“主人”

- **背景**：用户要求“把对象改为‘主人’”，预览是本地个人助手的人设。
- **选择**：首屏问候、模型消息开头、模型简报、404 文案使用“主人”；其余叙述保持中性。
- **影响**：这是产品文案偏好，不是技术约束；正式前端若采用需同步产品说明。

## D5 删除无依据的日期与天数

- **背景**：预览曾出现“2026-11-10 · 期末周第 12 天”，但 `demo_data.csv` **没有日期列**，
  数字与生成脚本也对不上（期末压力在脚本第 30–37 天）。
- **选择**：删除日历日期、星期、“第 N 天”、`10-28 → 11-10`、`11 月 17 日` 等；
  改用相对表达（最近 14 天、昨夜、明日）或“示例数据”标注。
- **理由**：数据诚实优先；无来源的日期一旦被追问就会露馅。
- **影响**：若将来要显示真实日期，必须由后端在 `/api/demo` 增加 `date` 字段。

## D6 占位数据必须显式标注

- **背景**：参考页结构需要睡眠阶段、计划、补剂、生物年龄等模块，但项目没有这些真实输出。
- **选择**：保留模块，页面打「示例数据 / 示例 / 占位」标；文档逐项说明。
- **理由**：评审看得见完整信息架构，又不会误以为已实现。
- **影响**：17 项指标中 7 项来自真实窗口，10 项是构造序列——改动数据前先确认来源。

## D7 预览与正式前端分离

- **背景**：需求文档要求“本次只输出 `presentation/`，确认后再动正式前端”。
- **选择**：预览先独立实现；评审后正式前端采用同一框架（2026-11-10 晚），两份文件仍独立。
- **影响**：两套代码会短时并存；正式改版时以预览为视觉基准，但需重新接接口、拆视图，
  **不能**直接把预览文件复制过去当成品。

## D8 演示数字以实验产物为准

- **背景**：PPT、口播、页面三处都要出现同一组数字，容易出现偏差。
- **选择**：以 `experiment/results.csv` 与 `demo_data.csv` 为准；
  页面上写 8.5 / 7.6 / 8.47 / 46.4→23.7 / MAE 0.729。
- **影响**：重训或改窗口后，这三处必须一起更新，否则答辩会自相矛盾。

## D9 品牌保留 WatchHealth-LSTM

- **背景**：中文化时曾把品牌译成「腕上健康」、logo 改「腕」；用户随后要求英文名保留。
- **选择**：预览页与正式前端统一 `WatchHealth-LSTM`，logo 用 `W`；其余界面仍全中文。
- **影响**：页面标题、Header、页脚、`aria-label` 统一；品牌不参与翻译。
