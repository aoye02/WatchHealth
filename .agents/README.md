# .agents/ · AI 协作工作区

> 这里不是运行代码，也不参与构建。它是**给下一个 AI / 人看的交接区**：
> 目标、现状、决策、待办、参考资料都放这里，让接手者在 30 秒内知道“现在在哪、下一步做什么”。

## 0. 进场顺序（强制）

1. 先读根目录 [`AGENTS.md`](../AGENTS.md) —— 仓库级硬规则（代码风格、数据契约、红线）。
2. 再读本文件 —— 协作区怎么用。
3. 再读 `context/` 里**日期最新**的一份 —— 30 秒上下文。
4. 开工前看一眼 `state/todo.md` —— 当前待办与已知问题。
5. 收工前更新 `context/`（新增或改写当天文件）与 `state/todo.md`。

## 1. 目录约定

| 目录 | 放什么 | 什么时候写 |
|---|---|---|
| `context/` | 30 秒交接上下文：目标、现状、下一步、坑 | 每次工作结束前 |
| `decisions/` | 决策记录：背景、备选方案、结论、影响 | 做了不可逆/有争议的选择时 |
| `state/` | 进度与待办（`todo.md` 是唯一真相） | 进度变化时 |
| `notes/` | 参考资料：链接、配色、接口、命令 | 调研有结论时 |
| `templates/` | 写作模板 | 需要时复制 |

## 2. 文件规则（硬性）

1. **每个 `.md` ≤ 200 行**。超了就拆成多个文件，并在本文件或 `context/` 里互相链接。
2. 文件名用 **ASCII kebab-case + 日期前缀**：`2026-11-10-preview.md`；只有 `README.md`、`todo.md` 例外。
3. 全部中文；代码标识符、命令、路径保持原样。
4. **不粘贴大段代码/文档**，用“仓库相对路径 + 行号”引用，例如 `presentation/index.html:714`。
5. **不写密钥、Token、个人隐私、绝对路径**（`C:\Users\...` 一律换成仓库相对路径）。
6. 每条关键信息标注来源：`[已验证]`（跑过命令/读过代码）、`[待确认]`（等人拍板）、`[推测]`（未验证）。
7. 过期内容**直接改写**，不要层层追加“更正：……”。
8. 不写“我今天做了什么”的流水账，只写对下一个接手者有用的结论。

## 3. 30 秒上下文怎么写

一份好的 `context/` 文件应能在 30 秒内回答：

- **一句话目标**是什么？
- **现在在哪**（能跑吗？哪部分是旧的）？
- **下一步**做什么，等谁确认？
- **哪些坑**绝对不能踩？

模板见 `templates/context.md`。建议控制在 60–120 行。

| 文件 | 作用 |

## 5. 与 AGENTS.md 的分工

- `AGENTS.md`：**仓库级**规则——代码风格、数据契约、红线、提交规范。违反会出事故。
- `.agents/`：**任务级**上下文——这次做到哪、为什么这样做、下一步。
- 两者冲突时，以 `AGENTS.md` 与用户当次指令为准；发现冲突要指出并修正。

## 6. 自检命令

```powershell
# 检查本目录所有 md 是否超 200 行
Get-ChildItem .agents -Recurse -Filter *.md | ForEach-Object {
  $n = (Get-Content -Encoding UTF8 $_.FullName).Count
  "{0,4} 行  {1}" -f $n, $_.FullName.Replace((Get-Location).Path + '\', '')
  if ($n -gt 200) { Write-Host "  ↑ 超过 200 行，需要拆分" -ForegroundColor Red }
}
```

> 注意：Windows PowerShell 默认按 ANSI 解码无 BOM 的 UTF-8 文件，中文会乱码、行数会少算。
> 统计行数、看中文内容一律加 `-Encoding UTF8`。

## 7. 纳入版本管理

- `.agents/` 建议随仓库提交（全部为文档，无敏感信息），方便换机器/换 agent 继续。
- 不把它放进任何构建、部署、`sys.path`、静态资源目录。
- 若某份上下文只对一次性实验有效，用完删除，不要留垃圾。
