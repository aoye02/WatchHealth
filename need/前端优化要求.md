# 任务：将健康看板前端改造为 Mira Bio 风格（保留本地模型聊天与明日状态预测）

## 背景
现有项目包含前端与后端，后端数据暂不改动。本次只做前端视觉与结构的改造。
目标是在 `presentation/` 文件夹下先生成一版静态 HTML 预览，供评审确认后
再动正式代码。

## 目标
将前端改造为参考 `https://www.framer.com/marketplace/templates/mira-bio/`
的页面结构与视觉风格，先生成一版以 `.html` 为后缀的静态页面放到
`presentation/` 文件夹下。改造需同时保留本项目已有的两个功能：
**本地模型聊天** 与 **明日状态预测**。

## 改造前：原前端功能盘点（必须先做）
在生成预览前，先通读原有前端代码，梳理页面、路由、组件与数据字段，
对每一项功能给出判断并产出对照表：
- **保留**：核心功能，改造后必须存在，并在 Mira Bio 结构中找到对应位置。
- **合并**：可与 Mira Bio 对应模块合并呈现，不单独占位。
- **弱化/替换**：与 Mira Bio 风格冲突，或被其模块替代；需注明理由。
- **新增**：原前端没有、本次按参考页补上的模块。

判断原则：
1. 两个既有功能（本地模型聊天、明日状态预测）必须保留，不得弱化或替换。
2. 与健康数据展示、指标、睡眠、计划直接相关的功能优先保留。
3. 仅当功能与 Mira Bio 的页面职责重复且无额外信息时，才考虑合并。
4. 任何「弱化/替换」的决定都要写明理由，供评审复核。

产出：一张「原前端功能 → 保留/合并/弱化/替换 → 对应 Mira Bio 位置」的对照表，
作为预览交付的一部分。若原前端有页面清单或结构说明，附在此处：
（页面清单 / 组件 / 字段 / 文件路径）

## 参考页面的结构（需在预览中体现）
1. **整体风格**：浅色、柔和、安静，lime 色作为强调色，等宽字体（mono）作标签。
2. **页面组成**（参考页共 5 页，本次预览做核心页面）：
   - **Overview**：聚合页，包含需关注的指标、生物学年龄、睡眠、今日计划、
     **本地模型聊天**、**明日状态预测**。
   - **Biomarkers**：列出 17 项指标，对照其最佳范围展示，点击可打开详情卡片
     （含趋势图）。
   - **Sleep**：展示睡眠阶段、评分、就寝时间。
   - **Plan**：三个重点领域、每日清单、补剂。
   - **Care**：医生对话线程与预约卡片（参考页原有内容，按需保留或弱化）。
   - **404**。
3. **本项目原有功能（需在预览中占位体现）**：
   - **本地模型聊天**：替代参考页 Care 页的医生对话线程，改为与本地模型的
     对话界面（消息气泡、输入框、发送按钮），预览版用示例对话占位。
   - **明日状态预测**：在 Overview 中以独立卡片呈现，展示明日状态的预测结果
     与简要依据（如评分/趋势/建议），预览版用示例数据占位。
4. **交互要点**（静态版先做视觉呈现，交互标注为待实现）：
   - 点击任一指标打开详情卡片（趋势图）。
   - 按状态（Optimal / Watch / Low）与分类筛选指标，筛选条件可组合。
   - 本地模型聊天：输入框与发送按钮可呈现，实际对话逻辑标注待实现。
   - 明日状态预测卡片可呈现结果与依据，刷新/更新逻辑标注待实现。
   - 每日清单可勾选。
   - 卡片与图表在页面加载时入场动画。
5. **响应式**：桌面、平板、手机三档；手机上标签栏移至底部。
6. **设计规范参考**：22 个文本样式（Geist / Geist Mono）、37 个颜色 token；
   组件命名如 Header、Marker Row、Category Item、Status Chip、Check Row、
   Clinician Item、Day Chip、Slot Chip、booking buttons。
   本地模型聊天与明日状态预测卡片需新增命名组件（如 Chat Panel、Message
   Bubble、Prediction Card）。
